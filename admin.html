Не удалось определить сайт автоматически. Откройте эту страницу по адресу вашего сайта на GitHub Pages.

Иконка 🖼 в углу товара — загрузить или заменить картинку. Изображение обрезается до квадрата 70×70 и при сохранении записывается в репозиторий под именем товара (как указано в поле «Название предмета»). При удалении товара его картинка тоже удаляется из репозитория — но тоже только при нажатии «Сохранить».
